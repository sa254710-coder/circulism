围圆会主义（Circulism）

大白话总结：
围圆会主义（Circulism）最核心的亮点在于它建立了一套“以失败为进化养分、以绝对反腐防范特权、以极端制衡拦截极权”的反脆弱元秩序：它彻底切断了权谋寻租与暗箱操作，通过“极端反腐”与“极端限制监督权”硬性并发，绝不给任何力量将暂时的优势转化为永久支配或特权阶层的机会；同时，它将自由试错引发的阵痛冷酷而客观地炼化为开源的《失败档案》，不仅能消解社会结构性内耗，更让每一次失败都转化为后来者跨世代演化的基因抗体与垫脚石，使全社会得以在免于被剥削与被支配的绝对安全感中，怀着纯粹的主体性与探索欲去拥抱未知的无限可能，让所有人可以说出那句：
“万端并行，彼此作用,秩序可变，经验不灭”

一、核心定义

围圆会主义是一种以多元共存、限制支配与持续制度演化为核心的元政治秩序理论。

它试图通过共同元规则、分层自治、权力制衡、人民决策、制度纠错与历史经验传承，使不同社会力量能够在共同体内竞争、合作、相互影响与改变，同时限制任何一方将暂时优势转化为永久支配权的能力。

它不预设唯一正确的社会终点，也不要求自身永久存在。

二、系统的基本运行原则

所有极端从系统执行之初，就必须同时结合运行。

围圆会主义不是先建立正常制度，再逐渐进入极端状态。极端化的原则、约束与相互制衡，本来就是系统的组成部分。

系统中的各项原则同时运行、彼此影响，而不是依次执行。

例如：

- 极端反腐败与极端限制监督权同时运行。
- 极端公共动员与极端限制动员权同时运行。
- 极端人民决策与极端保护少数者的权利同时运行。
- 极端制度纠错与极端制度可替代性同时运行。
- 极端安全防范与极端限制安全机构的支配能力同时运行。
- 极端稳定需求与极端防止权力永久固化同时运行。
- 极端透明要求与极端保护个人隐私同时运行。
- 极端权力制衡与极端维持治理能力同时运行。

这些原则不会因为彼此冲突就被简单取消。它们必须共同参与系统运行，其相互作用也必须被纳入制度设计。

三、系统运行的核心循环

1. 共同运行： 所有极端原则同时发挥作用。
2. 相互制约： 不同原则限制彼此的权力与适用范围。
3. 相互催化： 一项原则可能改变其他原则的作用方式，产生新的结果。
4. 持续纠错： 检查整个系统的运行结果，而不只检查单一机构。
5. 记录经验： 保存有效机制、错误、失效条件及其因果关系。
6. 继承与修正： 后来者继承经过验证的经验，并重新检验其适用性。
7. 替代与演化： 当制度失效或出现更好的方案时，允许修正、拆解、重建或彻底替代。

这个循环并不保证所有原则能够永远保持平衡。它必须面对极端之间相互强化、相互冲突，甚至共同造成系统性失效的可能性。

四、反腐败与监督

任何机构都不能仅凭反腐败的使命获得永久豁免权。

监督者必须能够被监督，证据必须能够被质疑，裁决必须保留适当的复核渠道。

反腐败的目标是发现、调查和纠正权力滥用，而不是让审查权无限扩张。

系统必须同时处理两个极端：既不能放任腐败，也不能让反腐败机制本身成为新的支配力量。

五、人民决策与制度合法性

重大公共决策应当具有明确的授权来源，并允许人民了解信息、参与辩论、提出异议及选择替代方案。

专家负责解释事实、证据与风险，人民参与决定公共目标与价值优先次序。

多数人的决定不能自动剥夺少数人的基本权利，也不能永久关闭未来的和平更替渠道。

程序合法性不能取代对实际权力分布与人民真实参与能力的审查。

六、受约束的公共动员

系统必须保留迅速协调人员、资金、知识与公共资源的能力。

但动员能力不等于永久统治权。

公共动员应具有明确目标、合法授权、适当范围、复核期限、责任记录及权限退出机制。

动员结束后，临时权力必须依照既定程序结束或重新获得授权。

系统既要能够行动，也要限制行动能力被转化为不可挑战的永久权力。

七、反战与和平约束

和平解决争端应当优先。

使用武力必须接受法律授权、必要性、比例性及适用国际法的约束，并保留监督、复核与结束机制。

紧急状态不得自动成为无限战争权力或永久取消公共监督的理由。

反战并不意味着否定合法防卫，而是限制战争成为不受挑战的政治工具。

八、极端耦合与系统性失效

所有极端同时运行，不意味着它们必然互相抵消。

它们可能形成复杂的反馈关系。例如，反腐败扩大审查，审查增加复杂性，复杂性提高对专业人员的依赖，依赖又引发更多监督；与此同时，持续存在的风险可能推动动员与安全审查不断延长。

如果这些机制相互强化，而纠错、退出、权力制衡与人民挑战能力无法有效阻断反馈，系统就可能出现制度异化。

原本用于维护多元共存的原则，可能被重新解释为排除威胁；原本用于限制权力的程序，也可能在实质上帮助权力集中。

在特定极端条件下，这条失效路径可能走向法律形式仍然存在、实际多元竞争却已消失的统治结构，并进一步法西斯化。

但这是一条需要明确条件的系统失效模型，而不是已经证明所有类似制度在任何环境下都必然法西斯化的普遍定律。

九、失败记忆与累积纠错

系统失败后，不能只更换领导者或修改个别条文。

必须尽可能保存完整的失效记录，包括：

- 失败发生前的条件。
- 最早出现的异常信号。
- 各项极端原则之间的相互作用。
- 失败的完整因果链。
- 未能发挥作用的制衡与纠错机制。
- 造成的损害及其承担者。
- 经后续检验有效的修正措施。
- 尚未解决的问题与不同解释。

这些记录应当接受独立核验，并允许后人提出不同结论。

每次修正都应留下理由、适用范围、预期效果与实际结果。新的失败也必须成为新的历史经验。

第一次失败成为第二次的防线，第二次的新经验成为第三次的防线。

目标不是保证未来永远不犯错，而是让已经充分识别、记录并成功修正的同类错误越来越难以重演。

十、毁灭后的传承

制度终结，不代表所有思想与经验都必须随之消失。

后人可以保留有效原则、失败记录、经验证的修正与未解决的问题，也可以放弃原制度的名称、结构及其不再适用的机制。

重新采用前，必须重新检验旧有失效条件是否仍然存在。

如果原来的错误根源没有被解决，单纯重建同一套制度，就可能重复过去的失败。

传承不是原样复制，而是让后来者拥有更好的起点。

十一、垫脚石原则

围圆会主义不要求自己成为历史的最终答案。

它允许自己被批判、被修改、被超越，甚至被彻底遗忘。

它的价值不只在于制度运行期间取得什么成果，也在于终结之后留下了什么知识，以及这些知识能否帮助后来者避免重复历史错误。

后人可以站在这块垫脚石上，建立更好的制度，甚至走向完全不同的思想方向。

十二、最终目标

围圆会主义试图同时面对以下问题：

- 如何限制永久支配。
- 如何在极端原则同时运行时维持有效治理。
- 如何防止反腐败、监督、安全与动员机制成为新的支配力量。
- 如何识别极端之间的相互强化与系统性失效。
- 如何保存失败经验并转化为后续制度的防线。
- 如何让制度终结后的经验继续被研究、修正与采用。
- 如何允许后来者超越自身，而不必重复自身已经付出的代价。

它不以永久存续证明自己成功，也不把失败本身浪漫化。

它追求的是让失败留下可以验证的知识，让知识转化为纠错能力，再让纠错经验成为后来者继续前进的起点
口号：
​“万端并行，彼此作用，秩序可变，经验不灭”
